Вайчжуань XII

Павел Юрич · около 1 мин чтения

♪ Главная тема циклаЗаставка

Из описи, найденной в доме отставного цензора.

Составлена его рукой за одну ночь. В служебные ведомости не внесена.

Трактат о воспитании чувств, имя составителя вырезано.
Листов по каталогу: сорок два.
Листов в наличии: тридцать один.
Изъято мною.

Наставления учителя ученикам, имя учителя стерто, три свитка.
Свитков в наличии: один.
Изъято моим предшественником.

Спор о природе Даров, запись беседы четырех наставников.
Строк по каталогу: шестьсот.
Строк в наличии: двести.
Изъято по распоряжению Палаты Ритуалов. Кем именно, не указано.

Родословная книга деревни Шанхэ.
Имен по переписи: сто девять.
Имен в наличии: девяносто.
Исправлено мною. Тогда это называлось уточнением.

Указ о Школе Единого Пути.
Строк по каталогу: неизвестно.
Строк в наличии: четыре.
Изъято до меня.

Песня о трех дорогах.
В каталогах не значится.
На бумаге не обнаружена.
Строк, которые я помню: девять.
Строк, которых не хватает: не знаю. Считал до рассвета, каждый раз выходит больше.
Изъять не представляется возможным, поскольку текст хранится не в архиве.

Приписка другим почерком.
Опись приобщена к лекарскому заключению. Составителю предписаны отдых и молитвы. Нож для бумаги из комнаты убран.
