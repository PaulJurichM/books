# Павел Юрич. Проза

Сайт для свободного чтения: сборники прозы, светлая и тёмная тема. Хронотопы живут отдельно, в разделе «Творчество» на malari.me.

- `content/` — тексты. Папка = сборник, файл = произведение; номер в имени задаёт порядок.
- `pages/` — отдельные страницы (экранизация и права).
- `assets/` — стили и скрипт.
- `build.py` — собирает всё в `docs/`, эту папку публикует GitHub Pages.

Добавить рассказ: положить `.md` в папку сборника и запустить `python3 build.py`.
В тексте `## ` — заголовок главы, `*так*` — курсив, строки с `> ` — цитата (эпиграф, письмо).
Иллюстрации сборника кладутся в `content/<сборник>/images/`; имя файла совпадает с именем рассказа без номера.
Строка `caption:` в шапке файла даёт подпись под иллюстрацией.

Все тексты © Павел Юрич. Читать можно свободно; перепечатка и экранизация по согласованию с автором.


Если в шапке файла стоит `section: yes`, произведение считается разделом: в оглавлении сборника оно выделено, а следующие за ним файлы идут под ним вложенным списком без номеров.

Строка `part: Название` в шапке файла открывает часть сборника: в оглавлении над этим рассказом появляется подзаголовок, нумерация остаётся сквозной. Строка `alias: старый-адрес` в шапке файла собирает переадресации со старых ссылок для этого рассказа и всех следующих за ним в сборнике.

Файл со строкой `url: https://…` в шапке — внешняя ссылка: в оглавлении она есть, отдельной страницы у неё нет.

Главная тема цикла: файл `content/<сборник>/theme.mp3`. Если он есть, на странице сборника и в начале каждого произведения появляется плеер.

Подпись в конце текста: строка `written: 2025-03` в шапке даёт курсивом «Тбилиси, март 2025». Если текст переработан, строка `revised: 2026-10` добавляет вторую дату: «Тбилиси, март 2025 — октябрь 2026». У параграфов учебника в «Двадцатом, на бис!» подписи нет: это документ мира книги.

Главная — полки сборников. Список полок, их порядок, названия и подписи заданы в `SHELVES` в начале `build.py`. Сборник встаёт на полку строками в `_collection.md`: `shelf: history` (id полки) и `place: 3` (место на полке). Сборник без полки показывается внизу широкой карточкой «Вне циклов». Подпись плитки собирается из `kind:` (роман, цикл, сборник, повесть), `unit:` (рассказ, повесть, глава, дело — чем считать тексты) и `status:` (пишется, пополняется); `years:` ставит на обложку плашку с годами. В подсчёте не участвуют «От автора», «Предисловие», «Послесловие» и параграфы учебника (заголовок с «§»); `count_prefix: delo-` считает только файлы с таким началом имени. Блок «Новое на сайте» собирается сам: три сборника, где по `published.json` тексты появлялись последними; у них же на плитке плашка «новое». Переключатель «По полкам / По времени написания» показывает все сборники в порядке папок; выбор читателя запоминается. Если у цикла есть `theme.mp3`, на плитке кнопка ▶ с главной темой.

Плитки сборников с обложками. Обложка лежит в `content/<сборник>/cover.jpg` (квадрат 600×600); её готовит `python3 make_covers.py` из иллюстрации первого рассказа или из файла, указанного строкой `cover: images/файл.jpg` в `_collection.md`. Если иллюстраций нет, на плитке текстовая обложка с буквицей. Свою обложку можно просто положить как `cover.jpg`.

Поиск и превью. Каждая страница получает описание (первый обычный абзац текста), каноническую ссылку, карточку для соцсетей и мессенджеров (Open Graph: иллюстрация рассказа, обложка сборника или `assets/og.jpg`) и разметку schema.org. Строка `description:` в `_collection.md` задаёт описание сборника, если у него нет аннотации. `build.py` пишет `docs/sitemap.xml` (карта сайта для Яндекса и Google) и `docs/feed.xml` (RSS: последние 30 текстов). Дата появления текста на сайте хранится в `published.json`: новые тексты попадают туда сами при сборке, файл нужно коммитить вместе с ними.
